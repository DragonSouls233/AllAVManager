三、发现问题汇总
====================================================================

【BUG-01】PORNHUB 演员列表错误 - 国籍目录被识别为演员名
  严重度: 高
  表现: 演员列表显示"素人"(16部)、"俄罗斯"(13部)、"美国"(13部)等
        这些实际是国籍/分类目录名，而非真正的演员名
  根因: extract_actor_and_nationality() 函数中，当文件夹名为"俄罗斯"、"美国"
        等纯国籍名时，将其作为 actor_name 返回而非 nationality
  修复: ✅ 已在 extract_actor_and_nationality 中增加国籍字典匹配检测，
        纯国籍名作为 (None, nationality) 返回
  文件: MDCX-Server/app/tasks/pornhub_scanner.py

【BUG-02】国产演员列表错误 - 单字符/无效名被识别为演员名
  严重度: 中
  表现: 演员列表显示"V"(8318部)、"v"(8318部)、"1"(2313部)、"3"(1151部)、"5"等
  根因: extract_actor_from_folder() 兜底逻辑 return result if result else [name]
        对纯数字和单字符文件夹名也返回了原名称作为演员
  修复: ✅ 已增加过滤：单字符(非中文)和纯数字名不返回演员名
  文件: MDCX-Server/app/scraper/folder_actor.py

【BUG-03】JAV有码 封面/头像全部为 None
  严重度: 中
  表现: cover_url=None, avatar_url=None, status="pending"（未刮削状态）
  分析: 可能是媒体文件扫描后未运行刮削流程，或者NFO/封面路径读取逻辑有问题
  状态: 需进一步分析 importer/sync 和 output/nfo 相关代码

【BUG-04】FC2 演员数为 0
  严重度: 中
  表现: 有570部影片但演员数为0
  分析: FC2模块可能有专门的演员提取逻辑需要检查

【BUG-05】欧美 演员数为 0
  严重度: 中
  表现: 有2036部影片但演员数为0
  分析: 欧美模块的演员提取逻辑可能需要检查

【BUG-06】仪表盘 actors.total = 0
  严重度: 低
  表现: stats/dashboard 返回 actors.total=0, 但各模块实际有演员数据
  分析: 仪表盘的演员统计逻辑可能只统计了主数据库的 actor 表，未包含模块数据库
