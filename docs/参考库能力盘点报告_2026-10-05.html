七、许可证口径变更说明

本项目内部使用，许可证不作为使用门槛。GPL / AGPL / 无 LICENSE 与 MIT 同等可用，引用时在代码注释或文档里注明来源仓库即可。本报告「许可」列仅用于产出引用说明，不再表示可用性。

据此，前版本报告里「GPL/AGPL/无 LICENSE 只读禁抄」的结论已作废。放开后：

  • 可抄码项目：50 → 120 项（123 项里唯一仍不建议复用是 ref112——专有许可 + OTP 激活校验）。
  • ref07（PolyForm 非商业）与 ref32（Source-Available 含反绕过条款）虽仍有附加条款，但它们在评估里只是 E 档（仅取思路），不构成风险。
  • 价值最高的 ref114-amane（GPL）与 ref96-peach（AGPL）现在可以直接搬代码，这两项是解禁后收益最大的。
远端已死的仓库（本次同步确认，可用 python sync_update.py --prune-dead 清理）：ref22-mdcx-diy（Repository not found）、ref42-Kesuy-mdcx（Repository not found）、ref105-misspipe（HTTP 403，仓库被 GitHub 禁用）。
