### 修复的 3 个真实 bug（本次会话）
1. **播放端点 500（UnicodeEncodeError）** — `app/api/routes/anime_routes.py` `play_anime_video_file` 原
   `Content-Disposition: filename="{原始日文文件名}"`，HTTP 头强制 latin-1 编码 → 含日文/中文文件名抛
   `'latin-1' codec can't encode ...` → 全程 500 视频裂。修复：用 ASCII 的 `code` 作 filename 兜底 +

2. **网格卡片点击无法播放（视频 src 为空）** — `_movie_summary` 未含 `play_url`，前端 `AnimeMovies.vue`
   `<video :src="current.play_url">` 取到 undefined → 播放器空转。修复：给 `_movie_summary` 补
   `"play_url": f"/api/v1/anime/movies/{m.id}/play/file"`（与详情端点一致）。修复后浏览器点击卡片
   `readyState=4`（视频已缓冲可播）。
3. **缺失全局未捕获异常处理器** — `app/main.py` 原先无 handler，500 只回 "Internal Server Error" 无堆栈，
   极难排查（play 端点 500 最初仅见此字符串）。新增 `@app.exception_handler(Exception)` 写完整堆栈到
   app.log 并返回 JSON `{detail}`，便于后续排查。（注意：此 handler 对 404/认证类预期异常也可能兜底，
   属防御性改进，无副作用。）
